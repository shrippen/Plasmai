Features

⏱

Live Panel Timer

See your running project, activity, and elapsed time right in the Plasma panel. No extra windows needed.

⭐

Favorites & Recents

Pin frequently used project/activity pairs. Switch between tasks with a single click and a confirmation dialog.

📊

Statistics View

Hourly bar charts, project gantt view, activity donut charts. Today and week summaries at a glance.

🌅

Day Sparkline

Zoomed work-hours bar with sun/moon arcs, overtime segments, and hour ticks — all in the popup header.

🏷

Tags & Billable

Tag entries and mark them billable on new and running entries. Kimai and Toggl tags; all providers for billable.

🔐

KWallet Integration

API tokens are stored securely in KWallet. Multiple profiles per service with shared settings across instances.

✏️

Edit Running & Stopped

Edit the active entry's start time, project, and activity. Edit, delete, or split stopped recents from the overflow menu.

💤

Idle Auto-Stop

Optionally stop tracking after idle time. Works on both X11 and Wayland with automatic detection.

🌍

Installation

1

KDE Store (recommended)

Search for Plasmai in Add Widgets, or install via the store:

kpackagetool6 -i Plasmai-1.6.2.plasmoid -t Plasma/Applet
2

From source

Clone the repository and install directly:

git clone https://github.com/shrippen/Plasmai.git cd Plasmai kpackagetool6 -i . -t Plasma/Applet
3

Configure

Right-click the widget → Configure Plasmai. Set your service, API token, and favorites in the connection tab.
