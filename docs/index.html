Plasmai

A native KDE Plasma 6 panel widget for time tracking with Kimai, Clockify, Toggl Track, and SolidTime.

kpackagetool6 -i Plasmai-1.6.3.plasmoid -t Plasma/Applet
Download the .plasmoid from the KDE Store or GitHub Releases, then run the command above.

Live Panel Timer

Running project, activity, and elapsed time in the Plasma panel. No extra windows.

Favorites & Recents

Pin project/activity pairs. Switch tasks with one click and a confirmation dialog.

Statistics

Hourly bar charts, project gantt, activity donut charts. Today and week at a glance.

Day Sparkline

Work-hours bar with sun/moon arcs, overtime segments, and hour ticks in the header.

Tags & Billable

Tag entries and mark billable. Kimai auto-resolves billable from activity/project/customer.

KWallet Secrets

API tokens stored in KWallet. Multiple profiles per service, shared across instances.

Edit Running & Stopped

Edit start time, project, activity. Split, delete, or edit stopped recents from the overflow menu.

Idle Auto-Stop

Stop tracking after idle time. X11 and Wayland with automatic detection.

Requirements

  • KDE Plasma 6
  • secret-tool (libsecret) for KWallet token storage
  • notify-send (libnotify) for desktop notifications
  • xprintidle (X11) or loginctl (Wayland) for idle detection — optional
  • A supported time tracker with API access

Setup

  • Right-click the panel → Add Widgets → search for Plasmai
  • Right-click the widget → Configure Plasmai
  • Connection tab: choose service, set URL, save API token, test
  • Favorites tab: pin frequently used project/activity pairs
  • Display / Behavior: recent count, panel labels, sparkline, idle, notifications
